### 🧠 Projetos em Dados & IA

**[titanic-ml-pipeline](https://github.com/IanzZm/titanic-ml-pipeline)** — pipeline de limpeza de dados + classificação (Random Forest otimizado via GridSearchCV). F1 macro 0.82.

**[mnist-cnn-classifier](https://github.com/IanzZm/mnist-cnn-classifier)** — classificador de dígitos (MNIST) com CNN (Conv2D + MaxPooling) e EarlyStopping. Accuracy 0.9835. Tracking de experimentos com MLflow.

**[reconhecimento-facial](https://github.com/IanzZm/reconhecimento-facial)** — sistema de reconhecimento facial (cadastro + verificação) com embeddings via DeepFace, threshold ajustado pra reduzir falsos positivos.
